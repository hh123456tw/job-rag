# 跨模型複查（非 RAGAS）

- 目的：RAGAS 的評審與生成同為 DeepSeek，可能自我偏好。另請 GPT（經 Codex CLI，預設模型）用同一份答案與段落獨立複查。
- 做法：把答案拆成事實陳述，逐項判斷段落是否支持；規則見 judge_prompt.md；輸入 input.json（只含公開事實段落）；輸出 judge_gpt.json。
- 結果：20 題、260 個陳述全部「有支持」，忠實度平均 1.0，與 DeepSeek 的 RAGAS 一致。
- 限制：兩個評審都只量「答案有沒有依據」，不量答案對不對；20 題很少；GPT 評審沒有用 RAGAS 流程，是同規則的獨立複查；結果全滿，仍需人工抽查。
