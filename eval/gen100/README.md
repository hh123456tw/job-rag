- 出題日期：2026-11-17
- 出題模型：Codex CLI 預設 GPT 模型，實際顯示為 `gpt-6.1-sol`（reasoning effort medium）。指令：`codex exec -s read-only --skip-git-repo-check`（唯讀）。
- Claude 只負責下指令、驗證、存檔，沒有自己出題。
- 題檔：`questions.json`。欄位沿用 eval/ 現有題檔（question、type、topic、company、answerable、gold = file + heading + quote）。不可回答題用 `absence_keywords`，跨公司題另有 `keywords`、`companies`。
- `raw/`：Codex 原始輸出、提示詞、重出紀錄。`verify.py`、`check.py`：驗證程式。

## 驗證結果

1. gold.quote 逐字比對：問題檔內 147 筆 gold 全數通過（檔案存在、標題路徑存在、quote 逐字在該標題段落內、標題不含 面試/評價/風險/判斷/推測/矛盾/未查到/對應/作戰/限制、沒用 00_ 檔與 104/ 資料夾）。第一輪 100 題中 92 題一次通過、8 題未通過。
2. 不可回答題：第一輪 8 題的關鍵字在語料（含子資料夾）有命中（加班費×3、試用×2、年終、健檢、餐補），全部重出。最終 18 題的 absence_keywords 在全語料 0 筆命中。重出過程中有 6 次因題材重複（寵物、凍卵）再重出一次。共重出 8 題，最終全數通過。
3. 與現有題檔（questions_heldout.json、questions.json）比對：正規化後字串完全相同 0 題。2 字元 bigram 相似度最高 0.53（"藍新資訊有哪些 AI 工程師職缺？" 對 heldout h34 "廣達電腦有哪些 AI 工程師職缺？"），公司不同、答案不同，保留。
4. 跨公司題：對 8 家公司的檔案用關鍵字 grep，gold 公司集合與 grep 結果一致（10 題中 9 題完全一致；AWS 一題 grep 多出凱基證券，該處為「查無」的否定句，不算符合，所以 gold 沒列）。
