# 34: 備援示範影片（螢幕錄製＋中文配音，HyperFrames 後製）

**Blocked by:** 無（不依賴票 33；用主專案正在跑的服務）
**Status:** ready-for-agent

背景：使用者要錄約 60 秒的備援影片（現場網路或服務掛掉時放給面試官看）。使用者原本要用真手機錄；現在請先做**手機尺寸的螢幕錄製版**，標明不是真機。

## 做法
1. 先讀並使用 `hyperframes`、`hyperframes-core`、`hyperframes-cli`、`media-use` 這些 skill 的流程（寫 composition 前必讀）。
2. 錄製：用 Playwright＋系統 Chrome，視窗 390×844、淺色，連本機服務 `http://127.0.0.1:5000`（存取碼取自 `dist/logs/public.out.txt` 的 `?k=`，只在本機用，不得寫進影片或 repo）。腳本：首頁 → 點公司（叡揚資訊）→ 預設題「薪水多少？」→ 看答案、點 [1] 展開原文與分數標籤 → 回首頁用跨公司題「哪些公司用 Python？」→ 看逐家答案 → 打開「專案說明」簡報模式翻 2 頁。真 DeepSeek 只呼叫約 6–8 次（每小時上限 100，不要多）。答案要等到出現再錄；若出現「查無」或錯誤就重錄，不得剪接成假結果。
3. 配音：繁體中文口語稿 ≤ 60–75 秒，短句，參考 `demo/` 的演示腳本；只說影片裡真的看得到的事，不誇大（例如不說「準確率 100%」）。用**免費、本機**的 TTS（先查 `media-use` 提供什麼）；若沒有可用的中文 TTS，停止並回報選項，**不要自行付費或申請帳號**。
4. 後製（HyperFrames）：片頭 3 秒標題「求職情報問答（示範錄影，電腦螢幕錄製，非真機）」；字幕（與配音逐句同步）；片尾 3 秒資料來源說明與限制。輸出 mp4（1080×1920 或 390×844 等比放大），存 `demo/backup_video/`（若 > 50MB 不進 git，只留 `.gitignore` 並在回報給路徑）。
5. 寫 `demo/備援影片說明.md`：怎麼重錄、口語稿全文、哪些是真的／哪些是示意。

## 不要做
- 不啟動 ngrok、不重啟或停止 5000 埠服務、不讀 `.env` 與 `selfdata/` 內容；不開自用模式（影片只用展示模式）。
- 不在影片、字幕、檔名出現存取碼或本人密碼。
- 不 push、不開 PR；影片不得宣稱是真手機錄的。

## 驗收
- [ ] mp4 可播放（用 ffprobe 或抽幀確認長度、解析度、有音軌）；你實際抽 4 幀以上看過
- [ ] 字幕與配音同步、無破字；片頭片尾有「非真機」聲明
- [ ] 回報：檔案路徑與大小、秒數、口語稿、真 DeepSeek 呼叫次數、沒做的（真手機）
