# 17: 手機現場展示的部署（筆電當伺服器，手機當螢幕）

**Blocked by:** 15
**Status:** ready-for-human

**What to build:** 讓使用者在現場用手機展示。最快、免費、免上傳資料的做法：筆電跑現有程式，手機和筆電連同一個網路（建議：筆電連手機熱點），手機瀏覽器開筆電的區網網址。

- [ ] 啟動檔可選擇對區網開放（例如環境變數控制監聽位址），預設仍只監聽本機；啟動時在畫面印出手機要開的網址（偵測筆電區網 IP）
- [ ] 若合理，主頁提供一個簡單方式顯示手機網址（不新增大型依賴；沒有就只印在啟動視窗）
- [ ] README 寫「現場 5 步驟」：開手機熱點 → 筆電連熱點 → 雙擊啟動檔 → 允許 Windows 防火牆（私人網路）→ 手機開網址；並寫常見問題（防火牆、IP 變動、熱點省電中斷）
- [ ] 預熱完成後再讓手機使用；「準備中」畫面在手機上正常
- [ ] 筆電斷網時：原文結果仍可用，「整理成答案」顯示明確錯誤（驗證）
- [ ] 需要使用者：用自己的手機實測一次並回報（我無法替你測）
- [ ] 不開放到公開網路；不上傳任何語料或金鑰
