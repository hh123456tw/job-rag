# 01: 端到端骨架（BM25）

**Blocked by:** None (can start immediately)
**Status:** resolved

**What to build:** 全部 16 家語料切成段落（依標題切、前綴公司名與標題路徑、過長再細切），分類為公開事實段落或私人段落，用 BM25（jieba 斷詞）檢索。一個最小問答頁：輸入問題，顯示前 3 段原文（公司、檔名、標題）。有演示模式（預設）與查詢模式（橘色橫幅）、可選公司。整個專案只有一個縫：檢索函式（輸入問題、檢索方式、模式、公司；輸出排序後段落，含公司、檔名、標題路徑、是否私人、分數）。

- [ ] 演示模式的結果不含任何私人段落（負向測試）
- [ ] 公司過濾後結果只含該公司
- [ ] 標題用完全比對分類；不在清單的標題（例如「風險備註」）歸私人
- [ ] 分類結果輸出成一張表（標題 × 公開／私人 × 段落數）給使用者檢查
- [ ] 語料路徑可設定；完整語料不進 git
- [ ] 檢索函式有測試，且不測內部實作細節
