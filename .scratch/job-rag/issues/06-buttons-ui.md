- 11 顆現場公司按鈕（點了之後的搜尋只在該公司內；可取消選取回到跨公司）。
- 4 顆常用問題按鈕：這家做什麼、有哪些職缺、用什麼技術、財務與新聞。點了就用目前選的公司代入句型送出；沒選公司時請使用者先選，或在跨公司範圍問。
- 2 顆「查無示範」按鈕：問句取自不可回答題（u 開頭），用來示範不亂編。
- 查無改為「可能沒有答案」：最高分低於門檻時顯示明確提示，**仍顯示原文結果（淡色）**，不出現「整理成答案」按鈕、不呼叫 DeepSeek。高於門檻時照常。
- 答案旁有「看這題在評估裡的成績」連結（只在問句與評估題完全相同時出現）。
- 沒有模式切換、沒有橘色橫幅（已取消）。

- [ ] 常用問題的句型與評估題的句型一致（「X 是做什麼的」「X 有哪些職缺／要會什麼技術」），並在 README 一行說明
- [ ] 兩顆查無示範的問題確實是不可回答題，點下去顯示「可能沒有答案」＋淡色原文，且沒有整理按鈕
- [ ] 選了公司後，結果只含該公司的段落（測試）
- [ ] 沒選公司按常用問題時有明確處理（不是靜默失敗）
- [ ] 手機寬度與筆電寬度都不需要橫向捲動，按鈕可單手點
- [ ] 頁面與 README 不含「AI 協作」類說明、不含私人內容
- [ ] 與評分器用同一個門檻值與檢索預設，不另設
