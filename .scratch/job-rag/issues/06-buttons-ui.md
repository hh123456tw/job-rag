# 06: 預設按鈕與模式切換介面

**Blocked by:** 02, 04
**Status:** ready-for-agent

**What to build:** 11 顆現場公司按鈕（點了只搜該家）、6 顆常用問題（這家做什麼、有哪些職缺、面試會問什麼、有什麼風險、我可以問他們什麼、我的專案哪個對得上）、2 顆查無示範、右上角模式切換與橘色橫幅、答案旁「看這題的評估成績」連結。按鈕問題文字取自評估題。

- [ ] 每顆按鈕的問題都存在於評估題
- [ ] 兩顆查無示範的答案確實不在語料，且系統回查無
- [ ] 預設為演示模式；切到查詢模式有明顯橘色標示
- [ ] 演示模式下點「有什麼風險」不會顯示私人段落
