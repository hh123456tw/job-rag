# 20: 公開網址（ngrok）前的存取保護與啟動檔

**Blocked by:** 票 17（已完成）
**Status:** ready-for-agent

**What to build:** 使用者要在這台筆電運行工具，並用已安裝且已設好帳號的 ngrok 提供公開 https 網址，給面試官用手機看。因為網址在公網上、「整理成答案」會花使用者的 DeepSeek 額度，先加存取保護與用量上限，再做一鍵啟動檔。

- [ ] 存取碼：環境變數 `JOB_RAG_ACCESS_CODE` 有值時，所有頁面都要帶正確的 `?k=<碼>`（第一次帶了就存成 cookie，之後不用再帶）；沒帶或錯誤回 403 與一句簡單說明。`/static` 圖示與 `/manifest.webmanifest` 不受限（PWA 需要）。沒設環境變數時行為完全不變。存取碼比對用常數時間比對。
- [ ] 用量上限：「整理成答案」每小時全域最多 N 次（預設 30，環境變數可調），超過時顯示明確訊息，原文結果不受影響；測試用可注入的時鐘。
- [ ] `start_public.bat`：產生隨機存取碼（或用已設環境變數）、設 `JOB_RAG_ACCESS_CODE`、只監聽 127.0.0.1（不開區網）、啟動 app，等預熱完成後啟動 `ngrok http 5000`，從 ngrok 本機 API（`http://127.0.0.1:4040/api/tunnels`）取得公開網址，印出完整可分享網址（含 `?k=碼`）。關掉視窗時兩個行程都要結束。不得印出或寫入 ngrok authtoken 與 DeepSeek 金鑰。
- [ ] README 一節：怎麼啟動、網址格式、ngrok 免費版第一次開啟會有警告頁（手機點「Visit Site」）、如何關閉、風險（網址在公網上、DeepSeek 額度、筆電要保持開機與有網路）。
- [ ] 測試：403 與放行、cookie 行為、`/static` 與 manifest 不受限、近似錯誤碼（長度不同、空字串）被擋、用量上限與時鐘注入、沒設環境變數時既有測試全過。
