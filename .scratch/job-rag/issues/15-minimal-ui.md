# 15: 簡約風格前端改版（手機優先）

**Blocked by:** 05
**Status:** ready-for-agent

**What to build:** 用 `ui-ux-pro-max` 技能（先呼叫 Skill 工具 `ui-ux-pro-max:ui-ux-pro-max`）把問答頁與專案說明頁改成簡約風格，主要在手機上單手展示給面試官。功能與內容不變，只改版面與視覺。

- [ ] 簡約：少色（一個強調色＋中性色）、大量留白、清楚的字級層次、無花俏動畫；繁體中文字型有明確備援
- [ ] 手機優先：375 寬單手可操作，按鈕與連結點擊區至少 44px，輸入框不被鍵盤遮住，沒有橫向捲動；桌面同樣可用
- [ ] 淺色／深色主題跟隨系統，兩種都可讀（對比足夠）
- [ ] 公司按鈕、常用問題、查無示範、原文結果、「可能沒有答案」提示、整理成答案按鈕、專案說明頁 6 塊內容，行為與文字不變（既有測試仍全過）
- [ ] 預熱「準備中」畫面也要簡約且清楚
- [ ] 用瀏覽器工具實際截圖驗證：手機寬與桌面寬、淺色與深色、查無示範、專案說明頁；回報貼出看到的
- [ ] 不新增大型前端依賴，不加「AI 協作」類文字，不含私人內容
