### 怎麼重錄與重做

前提：主服務在 5000 埠執行並已預熱（先確認 `/api/search` 回 200）；Python 有 playwright、edge-tts；有 Node 22、ffmpeg。工作目錄請用純英文路徑渲染（含中文路徑 Chrome 會當掉）。

```bash
pip install edge-tts
# 1. 錄製（本機直連不用存取碼；真 DeepSeek 呼叫 2 次；答案沒出現會以非零碼結束）
python -X utf8 demo/record_v3.py dist/rec/v3d 台灣大哥大 qa      # 簡報圖 + 首頁/單公司/跨公司（也會接著錄門檻頁，那段不呼叫模型）
python -X utf8 demo/record_v3.py dist/rec/v3e 台灣大哥大 th      # 只錄門檻頁（不呼叫模型）；想只重拍簡報圖：第三個參數用 slides
# 2. 配音（雲哲；服務偶爾回傳「沒有音訊」，腳本會重試；念稿沒變的句子沿用舊檔）
python -X utf8 demo/backup_video/tts_v3.py demo/backup_video/hf3/assets/voice
# 3. 切段、變速、產生時間線（產生 hf3/assets/screen.mp4 與 hf3/index.html）
python -X utf8 demo/backup_video/build_v3.py dist/rec/v3d dist/rec/v3e
# 4. 字型：hf3/assets/fonts/NotoSansTC-VF.ttf 不進 git（11 MB），從 Windows 字型資料夾複製
# 5. 複製 hf3 到英文路徑（如 C:/tmp/hf3），檢查並渲染
npx --yes hyperframes@0.9.56 check
npx --yes hyperframes@0.9.56 render --quality standard --output demo_backup_v3.mp4
```

分鏡（拉近座標、手繪圈、標籤、錄影秒數）在 `plan_v3.py`；旁白也在同一檔。重錄後各步驟秒數會不同：先看 `dist/rec/*/events.json`，改 `plan_v3.py` 的 `("raw", "qa"/"th", 起, 迄)`，再用 `npx hyperframes snapshot --at ...` 抽幀確認圈圈位置。響度：旁白音檔在 `build_v3.py` 設 `data-volume="1.55"`，渲染後約 -16.4 LUFS。

重錄注意（這次踩到的）：
- Playwright 內建錄影在這台機器只錄到 1 倍解析度，而且視窗被其他視窗遮住時，頁面更新不會畫進影片（答案出現後畫面不動）。所以 `record_v3.py` 改用 CDP 連拍，並加 `--disable-backgrounding-occluded-windows` 等啟動參數。
- 換頁（點公司）時進行中的截圖會卡住不回來：腳本逾時 1.5 秒就重開 CDP 連線。
- CDP 的 `clip.scale` 用整頁座標，捲動後會拍到空白；改用 `device_scale_factor`。

### 用到的 HyperFrames 與特效

- 取自 registry、改成自己的版本：`mesh-gradient-bg`（背景漂移漸層，CSS 變數補間）、`yt-circle-pointer`（手繪圈描邊動畫）、`caption-highlight`（關鍵字底色掃過，改成整句字幕＋關鍵字高亮）。其餘（轉場蓋板、拉近運鏡、放大標籤、片頭逐字動畫）是自寫。
- 轉場：品牌藍蓋板從右（或從下）掃過，板中央就是錄影的剪接點；板上是下一步的編號。
- 配音：每句一個 mp3（去頭尾靜音），句間停 0.22 秒；整支響度約 -16 LUFS；旁白是口語稿（第一人稱、短句），不是書面稿。

## 先講清楚：這支影片是什麼

- **電腦螢幕錄製，不是真手機。** 用 Playwright 驅動系統 Chrome，視窗 390x844、淺色，行動裝置模式，連本機 `127.0.0.1:5000`。片頭、畫面上方、片尾都標「非真機」。
- **答案是真的 DeepSeek 回應。** 錄製時真的呼叫 2 次（「薪水多少？」「哪些公司用 Python？」）。答案出現後才錄，沒有剪接成假結果。
- **全程展示模式。** 沒有點「進入自用」，沒有輸入本人密碼，畫面與檔名沒有存取碼（存取碼只在本機腳本用，從環境變數讀）。
- **配音是電腦合成語音**：Windows 內建 `Microsoft Hanhan Desktop`（zh-TW）。免費、本機、沒下載任何東西，沒帳號。
- **畫面有定格**：為了等旁白講完，部分片段把第一格或最後一格定格（沒有改動內容，沒有拼接不同時間的畫面）。每段旁白對應一段連續錄影。
- 畫面上的橘色圓圈是錄製腳本加的點擊提示，不是真手指。
- 「薪水多少？」不是叡揚資訊的預設題按鈕（沒有這顆），是在輸入框打字送出。

## 口語稿全文（依序，每行一段旁白）

1. 這是我做的求職資料問答。點一家公司，就能問問題。
2. 進到叡揚資訊。畫面先說這家有哪些資料，沒有哪些資料。
3. 我輸入：薪水多少。系統先搜尋，再整理答案。這一步真的呼叫了 DeepSeek。
4. 答案列出各職缺的薪資範圍。點一號來源，就看到原文和相似度分數。
5. 回到首頁，再問跨公司的題目：哪些公司用 Python。
6. 系統每家公司各找兩段，逐家回答。資料沒寫的，就直接說資料沒寫。
7. 最後是專案說明頁。我用簡報模式翻頁。評估題目和語料同源，數字只能當方向。

片頭（0–3 秒）：「求職情報問答（示範錄影，電腦螢幕錄製，非真機）」。
片尾（最後 4 秒，比規格的 3 秒長 1 秒，因為三行字 3 秒讀不完）：資料來源與限制三行。

## 怎麼重錄

前提：主服務在 5000 埠執行中；Python 有 playwright；有 Node 22、ffmpeg。工作目錄請用**純英文路徑**（HyperFrames 在含中文的路徑下 Chrome 會當掉，所以渲染時把 `hf/` 複製到英文路徑，例如 `C:\tmp\hf`）。

```bash
# 1. 錄製（存取碼放環境變數，不寫進檔案；真 DeepSeek 呼叫 2 次）
export JOB_RAG_KEY=<從 dist/logs/public.out.txt 的 ?k= 取得>
python -X utf8 demo/record_demo.py dist/rec/a1      # 產生 raw.webm、events.json；答案沒出現會以非零碼結束
# 2. 配音（Windows 內建 TTS）
powershell -NoProfile -File demo/backup_video/tts.ps1   # lines.json -> hf/assets/voice/n1..n7.wav
# 3. 切段、放大成 720x1558
python -X utf8 demo/backup_video/build_screen.py dist/rec/a1/raw.webm
# 4. 產生時間線（旁白長度、字幕時間寫在 gen_index.py）
python -X utf8 demo/backup_video/gen_index.py
# 5. 檢查與渲染（在英文路徑的 hf 副本內）
npx hyperframes check
npx hyperframes render --quality looks --output demo_backup_60s.mp4
```

重錄後旁白長度、各段起迄秒數可能不同：改 `build_screen.py` 的 `seg` 與 `gen_index.py` 的 `D`、`nar`、`cues`，再抽幀確認字幕與畫面同步。
