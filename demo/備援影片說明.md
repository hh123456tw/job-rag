### 用到的 HyperFrames 與特效

- 取自 registry、改成自己的版本：`mesh-gradient-bg`（背景漂移漸層，CSS 變數補間）、`yt-circle-pointer`（手繪圈描邊動畫）、`caption-highlight`（關鍵字底色掃過，改成整句字幕＋關鍵字高亮）。其餘（轉場蓋板、拉近運鏡、放大標籤、片頭逐字動畫）是自寫。
- 轉場：品牌藍蓋板從右（或從下）掃過，板中央就是錄影的剪接點；板上是下一步的編號。
- 配音：每句一個 mp3（去頭尾靜音），句間停 0.22 秒；整支響度約 -16 LUFS；旁白是口語稿（第一人稱、短句），不是書面稿。

### 怎麼重做

英文路徑渲染（含中文路徑 Chrome 會當掉）。`hf2/assets/fonts/NotoSansTC-VF.ttf` 不進 git（11 MB），請從 Windows 字型資料夾複製。

```bash
pip install edge-tts
export JOB_RAG_KEY=<從 dist/logs/public.out.txt 的 ?k= 取得>
python -X utf8 demo/record_demo.py dist/rec/v2 台灣大哥大          # 真 DeepSeek 2 次
python -X utf8 demo/backup_video/tts_v2.py demo/backup_video/hf2/assets/voice [voice]
python -X utf8 demo/backup_video/build_v2.py dist/rec/v2/raw.webm   # 產生 screen.mp4 與 index.html
# 複製 hf2 到英文路徑（如 C:/tmp/hf2），再：
npx hyperframes check && npx hyperframes render --quality standard --output demo_backup_v2.mp4
```

分鏡（拉近座標、手繪圈、標籤、錄影區段）在 `plan_v2.py`；旁白在 `lines_v2.json`。重錄後錄影時間會不同，要改 `plan_v2.py` 的 `raw` 並抽幀確認圈圈位置。

## 怎麼重錄

前提：主服務在 5000 埠執行中；Python 有 playwright；有 Node 22、ffmpeg。工作目錄請用**純英文路徑**（HyperFrames 在含中文的路徑下 Chrome 會當掉，所以渲染時把 `hf/` 複製到英文路徑，例如 `C:\tmp\hf`）。

```bash
# 1. 錄製（存取碼放環境變數，不寫進檔案；真 DeepSeek 呼叫 2 次）
export JOB_RAG_KEY=<從 dist/logs/public.out.txt 的 ?k= 取得>
python -X utf8 demo/record_demo.py dist/rec/a1      # 產生 raw.webm、events.json；答案沒出現會以非零碼結束
# 2. 配音（Windows 內建 TTS）
powershell -NoProfile -File demo/backup_video/tts.ps1   # lines.json -> hf/assets/voice/n1..n7.wav
# 3. 切段、放大成 720x1558
python -X utf8 demo/backup_video/build_screen.py dist/rec/a1/raw.webm
# 4. 產生時間線（旁白長度、字幕時間寫在 gen_index.py）
python -X utf8 demo/backup_video/gen_index.py
# 5. 檢查與渲染（在英文路徑的 hf 副本內）
npx hyperframes check
npx hyperframes render --quality looks --output demo_backup_60s.mp4
```

重錄後旁白長度、各段起迄秒數可能不同：改 `build_screen.py` 的 `seg` 與 `gen_index.py` 的 `D`、`nar`、`cues`，再抽幀確認字幕與畫面同步。
