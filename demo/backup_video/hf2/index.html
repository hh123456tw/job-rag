求職情報問答
想知道一家公司薪水多少？
你直接問就好。
嗨，這是我做的求職資料問答。
你看，點一家公司就能問。
那我先點台灣大哥大。
它先講有哪些資料，沒有哪些。
像員工人數、面試評價，沒有就說查無。
我來問一個：薪水多少？
它先找出五段相關資料，再丟給 DeepSeek 整理。
你看，這是真的 DeepSeek 回的。
資料分析師，月薪三萬五到四萬五。
Java 的職缺，年薪大概八十一到一百零八萬。
答案後面的編號，就是原文出處。
我點一號，原文就出來了。
相似度零點七三五，比門檻零點六二還高。
接著回首頁，我換個問法。
問跨公司的：哪些公司用 Python？
它每家公司各找兩段，一家一家答。
你看，台灣大哥大有 Python 全端工程師的職缺。
如果資料裡沒寫，它就老實說沒寫。
