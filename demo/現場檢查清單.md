# 現場檢查清單（個人用，不公開）

## 出門前

- [ ] 手機電量充飽，帶充電線與行動電源。展示期間手機要亮屏、插電。
- [ ] 確認手機電信方案允許開個人熱點、流量夠用。「整理成答案」要靠熱點連外網。
- [ ] 手機熱點：關掉自動關閉與省電模式。
- [ ] 筆電充飽電，帶電源線。電源選項：接電時不睡眠，闔上螢幕不睡眠。
- [ ] 啟動資料夾有 `.env`，裡面有變數名稱 `DEEPSEEK_API_KEY`，且已填值（不要把值寫在任何文件或截圖）。`.env` 要放在執行 `start_phone.bat` 的資料夾（程式讀的是工作目錄下的 `.env`）。
- [ ] 在家先用熱點完整跑一遍：雙擊 `start_phone.bat`，手機開網址，走完 `演示腳本.md`，包含「整理成答案」。確認答案框真的出現（準備工作時沒有驗證這一步）。
- [ ] 預熱：載入模型與索引要幾分鐘。到場前先啟動一次，讓防火牆設定與向量快取都在家完成。到場後重新啟動時仍要等「準備中」結束。
- [ ] 手機錄一段 60 秒流程備用（見 `備援說明.md`）。`demo/screens/` 的截圖也傳到手機相簿。
- [ ] 常用問題與查無示範各按一次，確認畫面與腳本相同。

## 到場後 5 步驟（引用 README「手機現場展示」）

1. 手機開「個人熱點」。
2. 筆電連上這個熱點。
3. 雙擊 `start_phone.bat`（或命令列 `start.bat phone`）。視窗會印出「手機請開：http://<IP>:5000」。
4. Windows 防火牆跳出視窗時，勾「私人網路」後按允許（只勾公用網路不夠）。
5. 手機瀏覽器輸入視窗印出的網址。載入約幾分鐘，畫面顯示「準備中」並自動重新整理；變成查詢頁再開始。

建議到場就先開機，輪到你之前確認已是查詢頁。

## 出問題時

| 狀況 | 處理 |
|---|---|
| 手機打不開網址 | 多半是防火牆。Windows 安全性 > 防火牆 > 允許應用程式，勾 Python 的「私人網路」。也確認手機與筆電在同一個熱點。 |
| 網址不一樣了（IP 變動） | 每次重連熱點 IP 可能變。關掉啟動視窗，重新雙擊 `start_phone.bat`，用新印出的網址。印出多個網址時，挑連到手機熱點的那個（標「最可能」的優先）。 |
| 熱點中斷 | 手機重開熱點，筆電重連，再依上一列換網址。來不及就播錄影或翻截圖，並直說「現場網路出問題，這是事先錄的」。 |
| 按「整理成答案」顯示紅字「整理失敗」 | 原文結果不受影響。直接講：「整理要連 DeepSeek，現場連不上；原文結果和出處在這裡。」重試不超過一次。 |
| 出現「可能沒有答案」 | 這是設計行為。可說明這是查無門檻；或把問句改成貼近段落用語（加「技術堆疊」「職缺」「營收」）。 |
| 被問到不會的 | 說「這我沒有量過」或「我沒有做過」，不要猜。見 `面試追問準備.md`。 |

## 不要做

- 不要把畫面或截圖貼到公開處（`demo/` 是個人用，公開匯出會排除）。
- 不要在現場換筆電或改設定；有問題就走備援。
