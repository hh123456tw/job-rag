# 現場檢查清單（個人用，不公開）

規則：這份文件與截圖不寫任何存取碼、密碼、token 或 API 金鑰的值。值只留在 `.env`、環境變數與啟動視窗。
演示用展示模式（預設）。不要打開自用模式。

## 先選現場方式

| | A：手機熱點直連 | B：ngrok 公開網址 |
|---|---|---|
| 啟動 | 雙擊 `start_phone.bat` | 雙擊 `start_public.bat` |
| 誰能連 | 同一個熱點內的手機 | 有網址的人（含存取碼） |
| 手機網址 | 視窗印的 `http://<IP>:5000` | 視窗印的 `https://<ngrok 網址>/?k=<存取碼>` |
| 需要 | 手機熱點；筆電連它 | 筆電有網路；ngrok 已安裝並設好帳號 |
| 第一次開啟 | 防火牆視窗要勾「私人網路」 | ngrok 警告頁要點「Visit Site」 |
| 用量上限 | 無 | 整理答案全域每小時 100 次（自動載入也算） |
| 筆電睡眠 | 不得睡眠 | 不得睡眠 |

自己用手機示範：選 A。要給面試官在自己手機上看：選 B（網址含存取碼，只傳給要看的人）。

## 出門前

- [ ] 手機電量充飽，帶充電線與行動電源。展示期間手機亮屏、插電。
- [ ] 筆電充飽電，帶電源線。電源選項：接電時不睡眠，闔上螢幕不睡眠。
- [ ] 手機方案允許個人熱點、流量夠用。熱點關掉自動關閉與省電模式。
- [ ] 啟動資料夾有 `.env`，裡面有變數名稱 `DEEPSEEK_API_KEY` 且已填值（值不寫進任何文件）。
- [ ] 預熱：在家先啟動一次（A 或 B 都要），等「準備中」結束，讓防火牆設定與向量快取都完成。到場重新啟動仍要等幾分鐘。
- [ ] 在家走完一次 `演示腳本.md`，包含點預設題目、等真實答案、展開原文、點後續題目、專案說明頁。`screens/` 的答案是替身，真實畫面要你自己確認。
- [ ] B 方案：確認 ngrok 在 PATH（`ngrok version`）、4040 埠沒有別的 ngrok 在跑。啟動視窗印出網址後，自己用手機開一次。
- [ ] 手機相簿放：60 秒螢幕錄影（見 `備援說明.md`）與 `demo/screens/` 的截圖。
- [ ] 確認畫面是展示模式（沒有橘色「資料會送到 DeepSeek」標示）。

## 到場後

**A：手機熱點直連**
1. 手機開「個人熱點」。
2. 筆電連上這個熱點。
3. 雙擊 `start_phone.bat`。視窗印出「手機請開：http://<IP>:5000」。
4. 防火牆跳出視窗時，勾「私人網路」後按允許（只勾公用網路不夠）。
5. 手機瀏覽器輸入該網址。畫面顯示「準備中」並自動重新整理，變成公司清單再開始。

**B：ngrok 公開網址**
1. 筆電連上可用的網路（或手機熱點）。
2. 雙擊 `start_public.bat`。視窗等模型載入完成（最多約 15 分鐘），再印出公開網址。
3. 手機開該網址。第一次出現 ngrok 警告頁，點「Visit Site」。第一次帶對存取碼後會存成 cookie，同一支手機之後不用再帶。
4. 確認看到公司清單。

兩種方式都：輪到你之前先開機並確認已是公司清單。點「台灣大哥大」→「財務與新聞」各走一次預熱。

## 出問題時

| 狀況 | 處理 |
|---|---|
| 手機打不開網址（A） | 多半是防火牆。Windows 安全性 > 防火牆 > 允許應用程式，勾 Python 的「私人網路」。確認手機與筆電在同一個熱點。 |
| IP 變動（A） | 每次重連熱點 IP 可能變。關掉啟動視窗，重新雙擊 `start_phone.bat`，用新印出的網址。印出多個網址時，挑連到手機熱點的那個（標「最可能」的優先）。 |
| 熱點中斷 | 手機重開熱點，筆電重連。A 要換新網址；B 要確認 ngrok 還在。來不及就播錄影或翻截圖，直說「現場網路出問題，這是事先錄的」。 |
| DeepSeek 失敗（紅字「整理失敗」或逾時 40 秒） | 原文自動展開，出處照常。直接講：「整理要連 DeepSeek，現場連不上；原文結果和出處在這裡。」不要重試超過一次。 |
| 存取碼無效，頁面 403（B） | 網址少了 `?k=存取碼`，或碼錯。回啟動視窗複製完整網址。不要在聊天或文件裡貼碼。 |
| 回 429、說已達用量上限（B） | 整理答案每小時全域 100 次，用完了。原文結果仍可看（搜尋不計次）。等幾分鐘，或關掉重啟（計數存在記憶體，重啟歸零）。 |
| ngrok 警告頁 | 點「Visit Site」。 |
| ngrok 啟動失敗 | 視窗寫「已有 ngrok」：關掉另一個 ngrok 再試。找不到 ngrok：改用 A。 |
| 出現「我找不到很接近的內容」 | 設計行為（查無門檻 0.700）。說明它是門檻；或點預設題目，預設題目已驗證沒被擋。 |
| 看到橘色自用標示 | 立刻切回展示模式，清掉自用對話；不要給別人看。 |
| 被問到不會的 | 說「這我沒有量過」或「我沒有做過」，不要猜。見 `面試追問準備.md`。 |

## 不要做

- 不要把畫面、網址或存取碼貼到公開處。
- 不要在現場換筆電或改設定；有問題就走備援。
- 不要打開自用模式。
