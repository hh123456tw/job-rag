# Triage Labels

Default vocabulary; each label string equals its role name.

| Role | Label |
| --- | --- |
| `needs-triage` | `needs-triage` |
| `needs-info` | `needs-info` |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix` | `wontfix` |

Local tracker: the label is the value of the ticket's `Status:` line. Done tickets use `Status: resolved`.
